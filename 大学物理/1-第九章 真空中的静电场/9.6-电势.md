# §9.6 电势

## 一、知识回顾：从电荷到电势的逻辑链

在引入电势之前，回顾静电场中概念的递进关系：

$$\text{电荷 } q \ \xrightarrow{\text{激发}} \ \text{电场 } \vec{E} \ \xrightarrow{\text{描述}} \ \begin{cases} \text{电场线（形象）} \\ \text{高斯定理（通量）} \\ \text{环路定理（保守性）} \\ \xrightarrow{\ } \text{电势 } U \text{（标量描述）} \end{cases}$$

- **电场强度** $\vec{E}$ 描述电场对电荷施加力的能力（矢量，与 $q_0$ 有关）
- **电势** $U$ 描述电场做功 / 储能的能力（标量，标准化描述）

两者是描述同一电场的**两个互补维度**——恰如函数与其导数的关系（详见 §9.7）。

> **💬 一条不严谨但好用的思维线索**（帮你在脑子里把概念串起来）：
>
> 电荷 $q$ 的存在 → 周围产生电场 → 电场传导力（库仑定律：$F \propto q_1q_2/r^2$）→ 引入 $\vec{E} = \vec{F}/q_0$ 描述场本身的性质 → 电场线形象化 → 高斯定理总览通量 → 环路定理揭示保守性 → 顺势定义**电势 $U$**。
>
> 如果把 $U$ 和 $\vec{E}$ 想象成两个互相垂直的维度：**电势像横轴**（标量，描述"高度"），**场强像纵轴**（矢量，描述"陡峭程度和方向"）。电势下降最快的方向就是场强的方向——和数学里梯度的关系一模一样。这样想虽然不够严密，但很直观。

## 二、电势的定义

### 电势能 → 电势

电场力将试探电荷 $q_0$ 从 $a$ 点移至 $b$ 点所做的功：

$$W_{ab} = q_0 \int_a^b \vec{E} \cdot \mathrm{d}\vec{l}$$

将此功除以 $q_0$（标准化），得到只与电场本身有关的物理量——**电势差**：

$$U_a - U_b = \frac{W_{ab}}{q_0} = \int_a^b \vec{E} \cdot \mathrm{d}\vec{l}$$

### 定义式

$$\boxed{U_a = \int_a^{\text{零势点}} \vec{E} \cdot \mathrm{d}\vec{l}}$$

电势是**标量**，单位：$\mathrm{V}$（伏特），$1\,\mathrm{V} = 1\,\mathrm{J/C}$。

## 三、电势零点

| 情形 | 零点选取 |
|:---:|:---:|
| 一般情形 | 取**无限远** $U_\infty = 0$ |
| 接地导体 | 大地为电势零点，接地导体 $U = 0$ |
| 特殊情形 | 可自行定义某处为零电势（如无限长带电直线须避免无穷远发散） |

## 四、电势差与功

已知两点间电势差 $U_a - U_b$，电荷 $q$ 通过时电场做的功为：

$$W_{ab} = q \, (U_a - U_b)$$

> 电势的实用价值正在于此——只需知道电势差而不必每次积分，即可直接求得电场力做功。

## 五、电势叠加原理

由电场叠加原理可直接推出——多个点电荷在某点的总电势 = 各点电荷单独在该点产生的电势的**代数和**（标量叠加，比场的矢量叠加更简便）：

$$U = \frac{1}{4\pi\varepsilon_0} \sum_{i} \frac{q_i}{r_i}$$

## 六、电偶极子的电势

### 推导

电偶极子 $(+q, -q)$，中心到考察点 $P$ 的位矢为 $\vec{r}$（$r \gg l$）：

$$U_P = \frac{1}{4\pi\varepsilon_0} \frac{q l \cos\theta}{r^2}$$

### 矢量形式

利用电偶极矩 $\vec{p} = q\vec{l}$：

$$\boxed{U = \frac{1}{4\pi\varepsilon_0} \frac{\vec{p} \cdot \vec{r}}{r^3}}$$

其中 $\vec{p}$ 的方向从 $-q$ 指向 $+q$，$\vec{r}$ 为从偶极子中心到考察点的位矢。

> **注意**：电偶极子电势 $\propto 1/r^2$（比点电荷电势 $\propto 1/r$ 衰减更快），且具有**角分布**（依赖 $\cos\theta$）。

## 七、电势与场强的对比

| | 电场强度 $\vec{E}$ | 电势 $U$ |
|:---:|:---:|:---:|
| 类型 | 矢量 | 标量 |
| 叠加方式 | 矢量叠加 | 代数叠加 |
| 与距离关系（点电荷） | $\propto 1/r^2$ | $\propto 1/r$ |
| 零点 | 不需定义零点 | 需定义零点 |
| 物理含义 | 单位电荷受力 | 单位电荷势能 |
