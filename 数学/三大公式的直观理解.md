# 三大公式的直观理解

## 一句话

**格林、高斯、斯托克斯——三个公式是同一句话在二维和三维的不同写法：**

$$
\text{边界上的总量} = \text{内部微小变化的累加}
$$

和牛顿-莱布尼茨公式 $F(b)-F(a)=\int_a^b F'(x)\mathrm{d}x$ 一样的道理，只是推广到了高维。

---

## 格林的两个面孔

格林公式在二维有两种形式，分别走向三维的两个公式：

| | 旋度形式 | 散度形式 |
|------|----------|----------|
| 左边 | 沿边界一圈的旋转 | 穿过边界的流量 |
| 右边 | 内部所有小漩涡之和 | 内部所有小水源之和 |
| **升维后** | → **斯托克斯公式** | → **高斯公式** |

---

## 升维：二维 → 三维

### 高斯公式（散度形式升级）

把平面区域 $D$ 变成空间立体 $V$，把曲线边界 $L$ 变成封闭曲面 $S$：

> 🏊 **一个气球**：表面往外渗水的总量 = 气球内部所有"冒水点"的总和。

### 斯托克斯公式（旋度形式升级）

二维旋度是一个数（正=逆时针，负=顺时针）。三维旋度变成了**向量**——多了"旋转轴方向"。

> 🌀 **一个陀螺**：旋转轴的方向 = 旋度向量的方向。积分时只取"贴合物面的那部分旋转"，所以要乘以法向量。

## 一张图

```
牛顿-莱布尼茨
    │ 推广
    ▼
 格林公式
    │
    ├── 散度形式 ──升维──→ 高斯公式（面→体）
    │
    └── 旋度形式 ──升维──→ 斯托克斯公式（线→面）
```

三个公式的终极统一形式：$\displaystyle\int_{\partial M}\omega = \int_M \mathrm{d}\omega$（边界上的积分 = 区域上微分的积分）
